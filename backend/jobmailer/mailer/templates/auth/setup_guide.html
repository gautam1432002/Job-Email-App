Setup Guide

Everything you need to get JobMailer running

Step 1 — Enable Google Login (Required)

  1. Go to console.cloud.google.com
  2. Create a new project — name it "JobMailer"
  3. APIs & Services → OAuth consent screen → External → Create
  4. Fill: App name "JobMailer", your support email → Save & Continue
  5. APIs & Services → Credentials → Create Credentials → OAuth 2.0 Client IDs
  6. Application type: Web application
  7. Name: "JobMailer Local"
  8. Authorized redirect URIs → Add exactly this URL:
    9. http://127.0.0.1:8000/accounts/google/login/callback/
  9. Click Create → Copy Client ID and Client Secret
  10. Open your .env in your project root
  11. Set GOOGLE_CLIENT_ID=paste_here
  12. Set GOOGLE_CLIENT_SECRET=paste_here
  13. Restart your server: python manage.py runserver
Important note: Also go to Django admin (127.0.0.1:8000/admin) → Sites → Change domain from example.com to 127.0.0.1:8000

Step 2 — Enable Email Sending (Required)

Open Google Security
  1. Go to myaccount.google.com/security
  2. Enable 2-Step Verification (this is strictly required first)
  3. Search for "App Passwords" in the top Google Account search bar
  4. Select App: Mail, Device: Other → type "JobMailer"
  5. Click Generate → Copy the 16-character password provided
  6. Sign in to JobMailer → Go to Settings → Paste in the App Password field
  7. Click Save → then Test Connection
Warning: You MUST have 2-Step Verification enabled on your Google account, otherwise the "App Passwords" option will not appear in the settings.

Step 3 — AI Email Personalization (Optional)

Open AI Studio
  1. Go to aistudio.google.com
  2. Sign in with your Google account
  3. Click "Get API Key" in the top navigation
  4. Click "Create API Key" → choose or create a project
  5. Copy the generated API Key
  6. Sign in to JobMailer → Go to Settings → Paste in the Gemini API Key field → Save
